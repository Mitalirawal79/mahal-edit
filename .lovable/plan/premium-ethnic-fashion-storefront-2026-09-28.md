# Premium ethnic fashion storefront

## Experience
- Create a fictional luxury Indian occasionwear brand as a sample storefront, with clearly illustrative products and prices.
- Make the home page feel like a fashion editorial: a photography-led opening, restrained wordmark and navigation, curated collection previews, a featured product edit, and a short brand story.
- Add a browsable shop with category/occasion filtering and search, individual product pages with image gallery and size selection, and a functional demo shopping bag. Include a dedicated brand-story page so the main navigation leads somewhere meaningful.
- Treat shopping as a sample experience: no accounts, live inventory, payment collection, or real checkout.

## Visual direction
- Use warm ivory, charcoal, and restrained maroon in a semantic design system; pair elegant serif display typography with a clean sans-serif for smaller text.
- Create cohesive fashion photography showing Indian ethnic garments clearly, using generous image scale, editorial grids, fine rules, open whitespace, and mostly square edges.
- Add smooth scrolling, restrained reveal/hover motion, and reduced-motion support. Fit desktop, tablet, and mobile, including a usable compact navigation and shopping bag.

## Technical approach
- Replace the blank home page in the existing TanStack Start app. Use separate routes for the shop, product details, and story, with distinct page metadata.
- Keep illustrative catalog data in the app and demo bag state in the browser; avoid backend setup because this is a sample storefront.
- Verify page rendering and core browsing/bag interactions at desktop and mobile sizes.
